Renew the issuing certificate

ATLAS signs device certificates with an issuing certificate. When it expires, every device stops authenticating. Renewing it needs the root key, which is deliberately not kept on this server.

Devices roll onto the new certificate by themselves — nothing needs to be done to any tablet.

Leave empty if the root key is still on this server. It is written for the length of one command and removed immediately afterwards, whether the command succeeds or fails.

Uninstall ATLAS

Removes ATLAS completely: containers, images, the database volume, the install directory, the Caddy vhosts, the firewall rule, and the ATLAS application in Authentik. Installing again rebuilds all of it from scratch.

⚠️ This destroys the device CA and the database. Every enrolled tablet's identity is signed by that CA. Once it is gone they cannot be re-adopted — each needs a factory reset, in person. There is no undo and no backup taken.
